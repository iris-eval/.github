# Security policy

Every repository in the iris-eval organization follows the policy of the Iris project: supported versions, response targets and how a report is handled are in [mcp-server's SECURITY.md](https://github.com/iris-eval/mcp-server/blob/main/SECURITY.md).

Report a vulnerability privately, never in a public issue: through [private vulnerability reporting](https://github.com/iris-eval/mcp-server/security/advisories/new) or by email to security@iris-eval.com.
